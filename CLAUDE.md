# Лендинг для услуг техспеца

## Что это
Одностраничный сайт-визитка. Я — техспец онлайн-школ, помогаю
с автоматизацией: ИИ-агенты, Salebot, AmoCRM, интеграции, Telegram-боты.

## Структура проекта
- index.html — единственный файл, всё внутри
- assets/ — картинки и иконки, если будут
- CLAUDE.md — этот файл

## Стек
- HTML, CSS, JavaScript (без фреймворков)
- Шрифты — Google Fonts: Inter (основной) + Space Grotesk (акцентный текст оффера в hero)
- Никакого Node, npm, сборщиков, бандлеров

## Стиль
- Фон сайта синий (#265876)
- Современный минимализм, карточки — полупрозрачные тёмные  (rgba(15,25,35,0.6)) с backdrop-filter blur, рамка в акцентном цвете
- Один акцентный цвет кирпичный/терракотовый (#a0522d)
- Жёлтый как акцент не использовать: на синем фоне пара «синий + жёлтый»
  считывается как флаг Украины — уже обсуждали и сознательно заменили
  на кирпичный
- Шрифт Inter, основной размер 17px
- Одинаковые отступы между всеми блоками: 80px десктоп / 40px мобильный, без разделительных линий между секциями

## Правила кода
- Все стили — в едином <style> внутри <head>
- CSS-переменные для цветов в :root
- Имена классов через дефис, на английском
- Никаких external CDN кроме Google Fonts
- Адаптив: один брейкпоинт @media (max-width: 768px)

## Правила контента
- Все тексты на русском
- Обращение на «ты»
- Не выдумывай цифры, кейсы, отзывы
- Для пустых мест — плейсхолдеры в [квадратных скобках]
- Если нужен текст, которого нет — спроси сначала
